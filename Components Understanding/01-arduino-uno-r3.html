Purpose

A microcontroller board: a tiny, single-job computer with pins you can wire to the real world. No OS, no screen — it runs one program (a sketch) forever, from power-on.

  • Prototype an idea in hours, not weeks
  • Learn electronics + code together, with instant physical feedback
  • Core of simple robots: read sensors → decide → drive motors

How it works

WriteSketch in Arduino IDE (C/C++)
UploadOver USB into 32 KB flash
setup()Runs once at power-on
loop()Runs forever, thousands of times/sec

Inside loop() you read inputs (digitalRead, analogRead), decide (if/else), and write outputs (digitalWrite, analogWrite). Power from USB or jack — jack wins if both are present, and both at once is safe.

Examples — try in this order

Blink (no wiring)

Proves the toolchain works. Uses the onboard L LED on pin 13.

void setup() { pinMode(13, OUTPUT); }
void loop() {
  digitalWrite(13, HIGH); delay(500);
  digitalWrite(13, LOW);  delay(500);
}

Button → LED

First input. Button between D2 and GND; internal pull-up, so pressed = LOW.

void setup() {
  pinMode(2, INPUT_PULLUP);
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, digitalRead(2) == LOW);
}

Light sensor → dimmer

Analog in → PWM out. LDR divider on A0, LED + 220 Ω on D9.

void setup() { Serial.begin(9600); }
void loop() {
  int v = analogRead(A0);      // 0–1023
  analogWrite(9, v / 4);       // 0–255
  Serial.println(v); delay(50);
}

Limits — don't cook the board

  • 20 mA per pin normal, 40 mA absolute max; 200 mA total across all pins
  • Always add a resistor (220–330 Ω) in series with an LED
  • Never drive a motor directly from a pin — use a driver or transistor
  • Pins are 5 V: 3.3 V-only sensors need a level shifter
  • Jack input 7–12 V; above 12 V the regulator overheats
  • Never short 5 V to GND; unplug before rewiring
  • Only 2 KB SRAM — large arrays/strings crash silently

Quick self-check

Which pins can dim an LED?

3, 5, 6, 9, 10, 11 — the ones marked ~ (PWM).

analogRead returns 512. What voltage is that?

≈2.5 V (512 / 1023 × 5 V).

Upload fails with a circuit on D0/D1. Why?

Those are the serial lines the USB upload uses. Disconnect them while uploading.

USB and 9 V adapter both plugged in — which powers it?

The jack. The board switches automatically; having both connected is safe.

For the kids: the Uno is a tiny brain. Its pins are fingers — some feel things, some push buttons on the world.
