# P-01 · Blinking LED

LED on pin 13 blinks: 1 s on, 1 s off. First end-to-end test: IDE → USB → chip → pin → light.

- **Parts:** Arduino Uno R3, 1 LED
- **Wiring:** long leg → 13, short leg → GND
- **Sketch:** [`BlinkingLED/BlinkingLED.ino`](BlinkingLED/BlinkingLED.ino) — open in Arduino IDE, Upload
- **One-pager:** [`index.html`](index.html)
- **Components:** [C-01 Arduino Uno R3](../../Components%20Understanding/01-arduino-uno-r3.html)
